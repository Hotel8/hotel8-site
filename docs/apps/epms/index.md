# ePMS - property staff app

The property management station for hotel staff: front-desk
operations, reservation management, housekeeping boards, cashiering,
and group blocks - everything PMS exposes, rendered for the staff
member's live role set.

## What it demonstrates

- **Role-driven surfaces** - a front-desk agent, a housekeeping
  supervisor, and a manager see different capabilities; access is
  decided per request by Shield against live-resolved roles.
- **Full-folio cashiering** - charges, payments, and settlements
  with the delegated payment path; every mutation CSRF-guarded
  through the BFF.
- **Operational dashboards** - arrivals, departures, in-house, and
  housekeeping status as live hook-driven views.
